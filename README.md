# Hackintosh_SL5
EFI folder for mackintosh on surface laptop 5.

you can download from releases page

# What works?
GPU acceleration (Metal2)

Keyboard

Trackpad

Battery status

Wifi

Bluetooth

Audio

Microphone

Brightness

Camera

Airdrop

# How to get ..
GPU acceleration: you need whateverxe 0.8.2 package file


Audio: you need simple hda 1.0.1 package file

# what you have to know
you need to generate smbios.
